🎮 Launcher Santi
Launcher No Premium de Minecraft Java — Creado por Santi ✨

=== Características ===
- No Premium — sin cuenta oficial
- Portable — todo en una carpeta
- Versiones desde 1.0 hasta 26.3
- Vanilla, OptiFine, Forge, Fabric, Quilt
- Skins y Capas sin iniciar sesión
- Sin ventana negra al abrir el juego

=== Cómo usar ===
- Opción 1: Ejecuta "Launcher Santi.exe" junto a la carpeta recursos
- Opción 2: Ejecuta con Python: python launcher_santi.py
- Opción 3: Crea tu propio .exe con PyInstaller

=== Requisitos ===
- Windows 10/11
- Python 3.8 o superior (solo si usas el código fuente)
